### 動作：「轉成 entry」中途狀態

```
┌── 虛線 muted (trigger disabled) ──┐
│ 13:00–14:00·1h                     │
│ PR Review                          │
│ ───────────────────────────────── │
│ 尚未轉成 entry                     │
│    [⟳ spinner] aria-busy=true     │
└────────────────────────────────────┘
```

### 成功後狀態 + toast

```
┌── 實線 success ──┐         ┌── Toast（右下） ──┐
│ 13:00–14:00·1h   │         │ ✓ 已轉成 entry   │
│ PR Review        │         │ [檢視 →]         │
│ ───────────────  │         └──────────────────┘
│ 已連結 → Entry ↗ │
│         [⋯ ▾]   │
└──────────────────┘
```

### 409 重複狀態

- toast warning「此事件已連結」
- Sheet 內該卡片 refetch 後自動變成 success 樣式
