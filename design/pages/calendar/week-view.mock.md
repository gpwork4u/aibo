### 視覺說明

- `[Ex..]` = entries chip（`Badge variant="secondary"`，truncate）
- `[+N]` = 溢出指示，點擊開啟 DayDetailSheet
- All-day 區塊橫跨多天：實線 primary/10 底
- 早於 06:00 chip：`[2]▾` 點擊 popover 列出事件
- 虛線邊框 EventBlock = 尚未連結的 gcal event
- 實線 + 綠色底 EventBlock = 已連結 entry 的 gcal event
- 4/24 header `●` = 選中 + today ring

### 尺寸

- 時間欄寬 56px
- 每日欄 flex-1，最小 80px
- 每小時高 48px（`h-12`）
- TimeGrid scrollable `max-h-[calc(100vh-320px)]`
- WeekHeader + chipsLane + allDayLane + earlyRow 合計高度 ~160px（sticky 頂部）
